What they already agree on — this is the system

Shared vocabulary, verified in all three sources
ConventionHow it is shared
Locked paletteThe same seven hex values, plus ink and cream, in every studio. Pickers offer the seven accents + ink + cream — never a free colour.
Weekday mappingIdentical to the app’s .d-* classes: Mon green · Tue blue · Wed purple · Thu pink · Fri red · Sat amber · Sun yellow, purple the only one taking paper. The Poster Studio surfaces it as tooltips on the accent picker so an event poster can match its night; the Schedule Studio uses it as the day-block fill.
Canonical wordmarkThe same vector outlines (Montserrat with Alternates forms for A, I, Y only) drawn from path data — never live-font text. Poster tickets, schedule headers and print PDFs all draw the same glyphs.
One real QRThe same 25×25 module matrix encoding https://realitydn.com. Exports scan. Print Studio adds a destination registry (site, check-in, menu, feedback…) rather than free-text URLs.
Full-bleed defaultEvery poster template opens with a full-bleed photo under duotone, contrast ~1.22, brightness −0.06, following the accent. Talk and Series close with the full-width REALITY banner; Nightlife and Sports take the standard ticket.
Swiss spineTemplates seed a shared left line at x = 90 and snap to it; multi-select align + edge-snapping exist to keep unequal boxes on one vertical.
Modular typeSizes snap to a scale rather than being typed: px 18→248 on poster canvases, pt 7→128 in print.
Forced text inkEvery text part can be forced to ink / cream / an accent, because legibility over a photograph beats inheritance.
Cloud documentsPoster and Schedule share one document store on the hub (/api/studio/documents), can attach a rendered poster to an event, and pull the live event feed.

The second ink is derived, not chosen

Misregistration partner map · riso-engine + print, identical
Pink→ blue
Red→ blue
Blue→ pink
Yellow→ pink
Amber→ purple
Green→ purple
Purple→ amber

Read this as canon

Every offset echo, overprint pass, cut-out edge, contour ghost and second spot band pulls its colour from this map unless an explicit second ink is set. It is warm/cool pairing, not a free choice — and it is implemented twice identically (the riso engine and the print exporter), which is what makes it a system rule rather than a default.

The tokens still describe --accent-2 as “defaults to blue”. That is true only for pink and red. See Canon — Open Questions §D.

What changed

The Photo Treatments card documents six. The shipped engine exposes thirteen plus untreated — filled in white above are the ones with no card here. Each also gained real dials: saturation, hue, temperature, tone smoothing, mid/high tint inks, paper field + texture, dot gain, jitter, pucker, and a two-band spot mode.

Start with Duotone still holds as the house default. The rest are range, not decoration — but they are undocumented range.

How to use this card

Poster Studio is the reference. When two studios disagree on a shared convention, its behaviour wins unless the difference is a substrate fact (the print column above) or a data-vs-canvas fact (the Schedule Studio never drags).

What is not settled — the accent lead, --accent-2 versus the partner map, print shadow values, the site string, and the weekday-hardcoding exemption — is catalogued in Canon — Open Questions §D. Don’t resolve them by copying whichever file you opened first.
