Wordmark, QR & AssetsCorrecting the record: the wordmark is not one font, and the spec that said so was wrong. Until now this only existed in a handoff README that had gone stale.CANON · 19.08.26

The correction

The mark is Montserrat, with Montserrat Alternates forms substituted for the A, I and Y only. The R, E, L and T stay Montserrat. Semi-Bold, all caps, tracked 0.1em. An earlier spec said "Montserrat Alternates" for the whole word — that was wrong and produced a visibly different mark.

You cannot get this from one CSS font-family. The letterforms are baked into assets/wordmark/reality-wordmark.svg. Ship the SVG. Don’t re-typeset it, don’t approximate it with a font stack, and don’t let a generator draw it from live text.

Rules

Clear space = cap height

On all four sides, measured from the mark’s own cap height. In the footer atom the rule above it counts as the boundary.

Ink or cream only

The mark is --fg or --bg. It never takes a palette colour, never sits in a coloured box, and never gets the misregister treatment.

Never re-typeset

No live-font wordmark in any generator, template or component. If a tool draws it from text, that tool is wrong — the Studio renders the vector for exactly this reason.

Never distort

Scale proportionally. No condensing to fit, no added tracking on top of the baked 0.1em, no outline or shadow.

The R stands alone

Where the full mark won’t fit, use reality-mark-R.svg — not a cropped wordmark and not a typed R.

One mark per surface

A poster has one wordmark, in the footer atom. A second one anywhere on the sheet is a mistake.

Two things to correct in code

The QR README contradicts D5. It states the printed URL stays www.realitydn.com “per the brand’s mandatory elements”. That was true when it was written; the 18.08 call made the bare host canon for artwork. The README needs the same edit as the generators — the encoded target is unaffected either way.

The www. sweep is wider than the audit recorded. It is in print-data, print-export, schedule-render, studio-data and public/event-report — not just Print Studio’s one constant. Roughly forty document presets carry it as a literal.
